# REACTIONATOR

This is a super simple reaction game that fits in one url that is under 3 kilobytes or KB. 

You can click to start, and what you have to do is wait for the green and then click to figure out your reaction time in milliseconds and the goal is to get super fast. 

The main source of all the code is in the index.html and in shrunk.txt there is a one line shortened version of basically everything. 

The html code contains 5 colours which basically represents 5 different screens.

- Blue = The start screen (when you click to play)
- Red = The waiting screen (ranges from 1 to 4 seconds)
- Green = The go screen (where you click to get your score in MS (milliseconds))
- Orange = If you click to early (clicking too fast)
- Purple = The time screen (where you get your score)
